# FoodLens 單餐量測紀錄表交接 v0.1

日期：2026-09-06。這份空白表用來記錄一餐的原始資料，不是官方報名附件、實測成果或校方許可。正式蒐集前仍須由學校核准範圍與保存方式。

## 成品與使用方式

- [可列印 PDF](../../output/pdf/FoodLens_單餐量測紀錄表_v0.1.pdf)：共 3 頁 A4，第 1–2 頁每餐雙面填寫，第 3 頁是網站回填說明。
- [可編輯 Word 母稿](../../output/competition/FoodLens_單餐量測紀錄表_v0.1.docx)：原生段落與表格，並非互動式表單控制項。跨裝置編修後，須重新輸出並核對排版。
- [試辦流程 v1.1](field-pilot-kit-v1.1.md)：與本表一起使用，原 v1.0 保留歷史。

第 1 頁包括菜單版本、實到人數、供餐重量、觀察範圍、五源逐容器秤重。第 2 頁包括匿名主要原因、缺餐與添餐人次、滿意度票數、情境、計時及覆核。數值一律留白，狀態不預勾；已量測為零與未取得資料分開記錄。餐盤照片另計，不增加獨立供餐日或觀察人數。

同來源多個容器可續印第 1 頁，使用同一餐期編號並填續頁數；先逐容器扣皮重再加總，同餐的供應重量與觀察人數只計一次。

## 與目前網站的界線

1. 五源資料尚缺、抽樣原供應量未量到時，先保留紙本待補；不填零強行完成正式案件。
2. 目前教師情境與原因欄沒有完整未知狀態，正式新餐期仍有配送延遲預填值。實際配送分鐘須核對；未收集的原因或未觀察的溫度，不以畫面預填、0 或未勾選代替。未確認前不標成完整資料。這是尚待修正的產品缺口，本表沒有修好網站程式。
3. 目前改善實驗只有一組護欄摘要，並非每天或前後各組的欄位。本表保留逐餐原始值，彙整時註明期別、日期、涵蓋範圍及缺漏，不宣稱網站已自動比較前後安全。
4. 製作量、送達量與實際操作計時，目前沒有對應的任務台專屬欄位；依說明另存原始紀錄，不用網站建立／更新時間代替計時。
5. 滿意度是待試辦的問題，不是經驗證量表。未知不填 0 分；跨餐計算按全部有效票數加權。缺餐和添餐以人次記錄，不直接當成人數或算成缺餐率。
