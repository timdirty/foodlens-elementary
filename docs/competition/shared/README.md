## 3. 證據狀態：不能用一個完成率包辦

每一主張同時記錄「證據種類」「驗收範圍」「資料身分」「具名審閱」，例如「已實作原型／本機驗證／Demo／學生待覆核」。

| 狀態代碼                | 顯示文字   | 最低證據／禁止延伸                                                      |
| ----------------------- | ---------- | ----------------------------------------------------------------------- |
| `official-source`       | 官方來源   | 來源、日期、頁次與精確主張；不延伸成未載明規則                          |
| `design-hypothesis`     | 設計假設   | 明示假設、受益者與待驗證方式；不是已訪談的需求                          |
| `implemented-prototype` | 已實作原型 | 程式位置、可操作流程與限制；不是已進校或商用                            |
| `local-verified`        | 本機驗證   | 指令、來源快照、結果、範圍、失敗與跳過；不是 hosted／真機／研究成效     |
| `field-pending`         | 待真實驗證 | 同意、協定、裝置、樣本與責任人未齊就保留待驗證                          |
| `artifact-frozen`       | 凍結文件   | 特定 DOCX／PDF、SHA-256、頁碼、字型、文字與版面驗收；不是後續程式最新版 |
| `named-review-pending`  | 待具名覆核 | 題目、素材、AI 使用、學生貢獻或校方文件尚待本人確認                     |
| `submission-receipted`  | 已送件存證 | 上傳後回讀同一檔案，留下正式回執與時間；本目錄目前無三案此項證據        |

資料身分另用 `Demo`、`Real`、`estimate`、`not-applicable`；`Real` 不自動表示有效、合格或可公開。資料不足不補零；未量測不填假數字；前後改變不直接宣稱因果。研究成效、模型準確率、秤重／聲學校正與真人輔具驗證，都必須各有對應證據。

FoodLens 後續[回饋 v2 應用驗收](../../audits/2026-09-06-feedback-v2.md)已把此規則落實於表單、草稿、備份、分析與新 SQL 契約：未知／已收集零回覆／舊值待複核分開，信心按真正有相關訊號的獨立日限制。這是後續產品紀錄，不改寫已凍結提案來源，也不表示其他兩案自動完成同樣實作。量測表配合[回填補充 v0.2](../field-record-handoff-v0.2.md)使用；原 v0.1 PDF 保留，舊來源指紋漂移不冒充重新驗收通過。

共用主張台帳欄位：`claim_id`、`statement`、`evidence_kind`、`dataset_mode`、`sample_and_period`、`unit_and_formula`、`source_snapshot`、`source_path`、`limitations`、`student_owner`、`named_review`、`used_in`。同一主張在 PDF 頁碼、網站路由、影片秒數、簡報頁碼之間可追溯。沒有具名資料時保持空白／pending，不填系統代理名字冒充學生。

## 5. 版本、凍結與下一步

1. **辨識母稿。** 以登錄表內 artifact 路徑為準；歷史 v0.1／v0.2 不刪除、不覆寫、不改名充當最新版。
2. **分開來源。** 文稿引用的 `source_snapshot` 不因 `latest_product_gate` 更新自動變更。新功能要先對照程式、再重截圖／改文稿、重新驗收後另出版本。
3. **先誠實再完成。** FoodLens v0.1 引用 Round 9 應用／Round 8 DB；ScamLens v0.4 引用 Round 43 契約／測試及 Round 41 截圖；SoundScape v0.3 引用 791／14 的局部工程紀錄及 09-05 歷史圖。三案格式已對齊，仍不是已取得正式研究或商用驗收。
4. **逐案覆核。** 按 [清單](./REVIEW-CHECKLIST.md) 填寫學生貢獻、來源、AI、素材、校方及資格事項。具名表存受控位置，不提交含個資的 public repo。
5. **保留發布事實。** 公開過的網站不能寫成從未公開；noindex 不等於非公開，Preview READY 不等於匿名可讀或參賽資格。主辦書面判定由校方／團隊取得，本工作不代寄、代簽、發布或送件。
6. **真正送出才記回執。** 核准後由指定人員上傳、回讀、比對指紋並存證；在那之前維持未送件。

## 6. 可重跑的文件檢查

使用 Codex 隨附 Python（`pypdf`、`pdfplumber`、`lxml`），不需要重新啟動網站、修改原稿或連線 Supabase：

```text
python3 scripts/test-shared-competition.py
python3 scripts/check-shared-competition.py --json output/shared-competition/check.json --markdown output/shared-competition/CHECK.md
python3 scripts/build-shared-entry-copy.py
```

`check` 為唯讀檢查，只有明確要求時才寫 FoodLens `output/shared-competition/` 報告；退出 0 只代表自動檢查通過，1 是發現不符，2 是資料未知。檢查分為指紋／大小、原生文字／頁數／字型／字級／圖片 alt、metadata 三類，另保留學生／校方待辦。字型會核對真正嵌入的字型程式名稱，不只相信 PDF 名稱；ScamLens 的 16 pt 只允許封面三行既有競賽名稱，沒有放寬正文。

2026-09-06 主代理重新執行：34 項共用回歸、FoodLens 提案 4 項與新量測表 4 項測試均通過。登錄 v0.3 的實際文件檢查為 **205 項通過、0 不符、0 未知**；先前 v0.2 的 47 項格式不符由原案新製 SoundScape v0.3 解決，沒有放寬字型或正文字級。報告只核對目前明確登錄的檔案，不批准真人覆核、校方研究、公開資格或送件。
