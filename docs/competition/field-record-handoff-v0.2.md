# FoodLens 量測表回填補充 v0.2

2026-09-06。更新網站回填方式，不是新 PDF、校方核准或實測結果。

原[紙本 v0.1／Word／PDF](field-record-handoff-v0.1.md)保留不變。前兩頁仍可記錄原始資料；原第 3 頁「網站尚無未知狀態」為修正前快照，現在請搭配本補充使用。

1. 未調查原因，選「尚未收集」，票數維持空白；可以保存有效重量證據，不必假填一票。
2. 完成收集，選「已收集，逐項確認票數」，沒有該原因才填 0。每人每餐一個主要原因，合計不超過實到人數。
3. 確實收集但沒有有效回覆，才使用「已收集但沒有回覆，全部記為 0 票」。這不代表全班沒有意見。
4. 配送未記錄就留空，確認未延遲才填 0 分鐘；溫度分為尚未觀察、有疑慮、已觀察沒有疑慮，不用未勾選代替觀察。
5. 舊紀錄保留原數字但標為待複核、不列入相關統計。依紙本查證後才採用原值或重填，配送複核不會順帶確認溫度。

狀態會保存於草稿、案件與 JSON 備份。校園雲端須先套用 v2 migration，未更新會明確停止而非用舊契約保存。詳見[本輪驗收](../audits/2026-09-06-feedback-v2.md)。

逐餐／前後各組的缺餐、添餐人次與滿意度、製作量、送達量、操作計時，仍依原紙本另存；網站尚未全部串成前後護欄比較。未取得的五源秤重也不可補 0 強行完成正式案件。

v0.1 原來源 ledger、DOCX、PDF 與目視紀錄未改；三個應用來源已更新，舊檢查器會如實提示 source drift。待逐餐護欄同步後，再另出完整新版表單並重新驗收，不把舊排版通過當作新版內容已對齊。
